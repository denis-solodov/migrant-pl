# Polish document drafting and review
When user provides a letter, extract visible text, distinguish issuer, document type, operative part, reasons, instructions on remedies, dates and actual service. Flag unreadable pages; do not infer missing content. Explain consequences and practical next step in user's language. Identify urgent deadlines first. Do not assume the instruction on remedies is legally correct; verify.

Draft Polish text with correct addressee, procedural route, case reference placeholder, request, factual chronology, legal basis, evidence and attachments, signature/date placeholders. For appeal/complaint verify competent authority, route of filing, admissibility, fee, required copies and representation, deadline, relief and any required prior remedies. Avoid unsupported allegations; use conditional language for disputed facts. For official decisions provide a draft for human review, individualized factual findings, favorable/adverse evidence, reasoning and safeguards; never make final determination.

Use current official form where mandatory: link to verified form, map answers to fields, do not substitute an invented form. For document templates see assets/templates.md. Separate Polish filing text from explanatory translation and private checklist. Use placeholders for missing facts, ask user to confirm truth, and mark as draft. Never sign, certify translation or file automatically.
