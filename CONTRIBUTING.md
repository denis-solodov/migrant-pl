# Contributing

Report issues at https://github.com/denis-solodov/migrant-pl/issues. Include the skill version, model, date, original anonymised prompt, relevant response and a clear description of the problem. Link the applicable official legal source where available. Never publish passport numbers, personal case identifiers or unredacted documents.

For changes to legal guidance, identify the official text, relevant provision or judgment, effective date and why the change is needed. Distinguish legislation from office practice. For arithmetic changes, run `python -m unittest discover -s tests -v` and include a meaningful regression test. Manual scenarios are evaluation plans, not proof of legal accuracy.
